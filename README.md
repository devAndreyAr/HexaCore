# HexaCore

Proyecto de ISW-322 Introducción a la Arquitectura del Software.
Arquitectura de software en Microsoft Azure para el Hospital Metropolitano "SaludCloud".

## Metodología
Scrum con sprints semanales. Gestión del backlog en Jira (enlace del tablero aquí).
Se usa Jira porque hubo problemas con la licencia de Azure DevOps.

## Estructura
- `docs/SAD/`: Documento de Arquitectura de Software por sprint
- `docs/diagramas/`: Diagramas UML
- `docs/evidencias-scrum/`: Capturas de Jira
- `src/`: Prototipo
